# Building glgrib

glgrib is built with CMake (3.18 or later). The makefiles (`make` at the top of the tree) still work
and produce the same files in `bin/`, `lib/` and `share/`; they will be removed later.

## Dependencies

On Debian or Ubuntu:

```sh
apt install cmake pkgconf g++ perl libperl-dev python3-dev \
  libgl-dev libegl-dev libglew-dev libglfw3-dev libglm-dev \
  libeccodes-dev libnetcdf-c++4-dev libshp-dev libpng-dev libreadline-dev \
  libsqlite3-dev libssl-dev libcurl4-openssl-dev
```

The constrained Delaunay triangulation library CDT is vendored in `include/CDT`. The Perl/Tk interface
(`glgrib-tk`) needs `perl-tk`, `libimage-magick-perl`, `libdbi-perl`, `libjson-perl` and
`libdbd-sqlite3-perl` at run time only.

## Build

```sh
cmake -S . -B build
cmake --build build -j
```

The build tree has the same layout as an installation, so the programs run from it without installing:

| Path in `build/` | Content |
| --- | --- |
| `bin/glgrib-glfw`, `bin/glgrib-egl`, `bin/glgrib` | Programs (`glgrib` is a link to `glgrib-glfw`) |
| `lib/libglGrib-glfw.so.0`, `lib/libglGrib-egl.so.0`, `lib/libLFI.so.0` | Libraries |
| `share/glgrib/shaders` | Shaders, with their `#include` directives expanded |
| `share/glgrib/{glGrib.db,coastlines,fonts,landscape,testdata}` | Links to the data of the source tree |
| `share/man/man1`, `share/man/man3` | Man pages |
| `perl5/` | Perl module: `perl -Ibuild/perl5 -MglGrib::glfw ...` |
| `python3/` | Python module: `PYTHONPATH=build/python3 python3 -c 'import glGrib.glfw'` |

```sh
build/bin/glgrib-egl --land.on --render.offscreen.on --render.offscreen.format land_%N.png
```

## Options

Set with `-D<option>=<value>` when configuring.

| Option | Default | Effect |
| --- | --- | --- |
| `GLGRIB_WITH_GLFW` | `ON` | GLFW backend: `libglGrib-glfw`, `glgrib-glfw`, `glgrib` |
| `GLGRIB_WITH_EGL` | `ON` | EGL backend: `libglGrib-egl`, `glgrib-egl` |
| `GLGRIB_WITH_GBM` | `OFF` | GBM support in the EGL backend (`-DGLGRIB_USE_GBM`, `-lgbm`) |
| `GLGRIB_WITH_PERL` | `ON` | Perl module `glGrib::glfw` and `glgrib-tk` (needs the GLFW backend) |
| `GLGRIB_WITH_PYTHON` | `ON` | Python module `glGrib.glfw` (needs the GLFW backend) |
| `GLGRIB_WITH_TOOLS` | `OFF` | `gshhs_clean` and `glGribDBase2SQLite`, built in `bin/`, not installed |
| `GLGRIB_WITH_MANPAGES` | `ON` | Man pages generated by running the programs with `--pod` |
| `GLGRIB_CHECK_BOUND` | `OFF` | Bound checking (debug) |
| `GLGRIB_PYTHON_INSTALL_DIR` | from Python | Install directory of the Python module |
| `GLGRIB_PERL_ARCH_INSTALL_DIR`, `GLGRIB_PERL_LIB_INSTALL_DIR` | from the prefix | Install directories of the Perl modules |
| `CMAKE_BUILD_TYPE` | `Release` | `Release` is `-O2` without `-DNDEBUG`, as the makefiles; `Debug` is `-g` |

## Install

```sh
cmake --install build --prefix /opt/glgrib
```

The libraries go to `<prefix>/lib/<multiarch>` when the prefix is `/usr`, and to `<prefix>/lib` otherwise.
Outside the system directories, the programs and modules get an rpath to the installed libraries.
With the prefix `/usr`, the Perl modules go to Perl's vendor directories; with another prefix, to
`<prefix>/lib/perl5` (add it to `PERL5LIB`).

## Tests

`scripts/runtest.pl` runs the regression cases (see `share/doc/glgrib/TECHNICAL.md`). By default it runs
`bin/glgrib` of the source tree; `GLGRIB_BIN` selects another program:

```sh
NAME=land AUTO=1 COMP=1 GLGRIB_BIN=build/bin/glgrib-egl scripts/runtest.pl
```

## Debian packages

`packaging/debian` builds the packages with `dh --buildsystem=cmake`. They are built and tested in the
Singularity containers of `scripts/singularity` (see the `README` there):

```sh
./scripts/singularity/singularity-create-build.sh       # once: build image ../singularity.glgrib-build
./scripts/singularity/singularity-create-install.sh     # once: install image ../singularity.glgrib-install
singularity exec --bind $HOME/tmp:/tmp ../singularity.glgrib-build ./scripts/singularity/debian-build.sh
```

`debian-build.sh` builds from the upstream tarball made by `scripts/debian/tar.pl`, which contains the files
tracked by git only: add new files with `git add` before building the packages. Debian unstable already
ships glgrib (1.0-6), so the version in `packaging/debian/changelog` must be higher for the local packages to
be installed instead of the archive ones.
